# Overview

Podcast Operating System is a process harness, not a locked-in app. It separates the podcast workflow into four layers:

1. **Process kernel**: universal steps every podcast needs.
2. **Recipes**: swappable instructions for editing, clips, show notes, and promotion.
3. **Prompt packs**: replaceable prompts for your voice/style.
4. **Connectors**: adapters for your CMS, storage, recording, editing, publishing, social, and analytics tools.

The default implementation is local-first and dry-run-first.
