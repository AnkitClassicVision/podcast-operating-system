# Podcast Production Skill

Follow the workflow spine:

1. Source guest/topic.
2. Research.
3. Brief.
4. Record.
5. Ingest assets.
6. Edit locally or via connector.
7. Generate content pack.
8. Export publishing/social drafts.
9. QA.
10. Archive.

Default to dry run and local export. Never publish externally without explicit approval.
