# Public Release Audit

This public repo was created as a clean sibling repo, not by making a private podcast operations repo public.

## Included

- Generic workflow docs
- Synthetic examples
- Connector interfaces and stubs
- Local FFmpeg editing workflow
- Promotion templates with placeholders
- Prompt packs and recipes
- Private-data scanner
- CI

## Excluded

- Private Git history
- Real episode folders
- Raw recordings
- Raw transcripts
- Guest contact details
- Real recording links
- Real publishing account IDs
- Real social account IDs
- Real API keys
- Internal logs and run-state files
- Proprietary private notes
